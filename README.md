# 机房座位预约小程序

面向高校机房的微信小程序演示项目：支持扫码签到、实时选座、分时段预约、空位订阅、用户反馈，以及带 RAG 检索的智能问答助手。数据层使用 `wx.setStorageSync` 模拟后端，导入即可运行。

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 账号 | 学生 / 教师注册登录，本地会话 |
| 扫码签到 | 教师端动态二维码（默认 60 秒刷新），支持 6 位签到码兜底 |
| 选座 / 退座 | 48 个座位实时状态，故障电脑不可选 |
| 预约 | 未来 7 天分时段预约，冲突校验与取消 |
| 订阅 | 订阅已被占用的座位，对方退订后站内提醒 |
| 反馈 | 功能建议 / 故障报错 / 其他问题，教师端可查看 |
| 智能问答 | 本地知识库 RAG，可选接入 OpenAI 兼容大模型 |

## 快速开始

1. 打开微信开发者工具，选择「导入项目」
2. 项目目录选择本仓库根目录
3. AppID 选择测试号（`project.config.json` 中为 `touristappid`）
4. 编译后使用测试账号登录

测试账号：

- 学生：`xiaoming / 123456`
- 教师：`teacher / 123456`

演示数据：A301 计算机机房，6 排 × 8 列共 48 个座位，其中 6 个已占用、4 个故障。

## 使用流程

### 学生端

1. 登录后首页查看座位分布与空闲统计
2. 扫描教师端大屏二维码签到，或手动输入 6 位签到码
3. 签到后点击空闲座位完成占座，「我的座位」可退座
4. 「预约选座」按日期和时段预约
5. 「我的订阅」查看空位提醒
6. 右上角「反馈」提交问题，或进入「智能问答」咨询

### 教师端

- 座位视图、学生名单、签到码、预约管理、反馈
- 可强制退座、取消学生预约

## 预约规则

- 可预约未来 7 天内的时段
- 每天 08:00–22:00，每小时一个时段，共 14 段
- 同一时段每人限约 1 个座位
- 同一座位同一时段只能被 1 人预约
- 已开始的时段不可预约
- 故障座位不可预约
- 预约开始前可取消

## 空位订阅

- 在预约页点开已被占用的座位，点击「有空位时提醒我」
- 该预约被取消（学生取消或教师取消）后，订阅状态变为「已释放」
- 学生下次进入首页时弹窗提醒，每条提醒只弹一次
- 可在「我的订阅」中取消订阅

## 智能问答

- 默认使用本地知识库，内置 FAQ，并支持实时数据查询：空闲座位、我的预约、座位推荐
- 检索方式：中文按单字 + 二元组切分，结合关键词加权打分，取 Top 3 片段作为 RAG 上下文
- 可选接入大模型：助手页「AI 设置」填写接口地址、模型、API Key，默认 `https://api.deepseek.com` + `deepseek-chat`
- 大模型调用失败时自动回退本地知识库
- 喂数据：编辑 `utils/kb.js` 中的 `KNOWLEDGE` 数组，或写入 storage 键 `lab_kb_custom_v1`

> 注意：API Key 保存在本机 storage，仅适合开发与演示；正式上线请改为后端代理调用。

## 数据存储

所有数据保存在小程序本地 storage：

| Key | 内容 |
| --- | --- |
| `lab_db_v1` | 用户与座位种子数据 |
| `lab_session_v1` | 登录会话 |
| `lab_checkins_v1` | 签到记录 |
| `lab_config_v1` | 二维码刷新间隔 |
| `lab_reservations_v1` | 预约记录 |
| `lab_subscriptions_v1` | 订阅记录 |
| `lab_feedback_v1` | 用户反馈 |
| `lab_ai_config_v1` | 大模型配置 |
| `lab_kb_custom_v1` | 自定义知识条目 |

在开发者工具中清除数据缓存后会恢复种子数据。

## 测试

## 已知限制

- 没有真实后端，数据仅保存在本机，多设备不互通
- 站内订阅提醒仅在打开小程序时触发
- 微信订阅消息推送需要模板 ID 与服务端
- 大模型密钥存放在客户端，仅限演示使用
